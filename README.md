# Orca Trading Bot 🐋

Self-learning cryptocurrency trading bot using reinforcement learning.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/[TON_USERNAME]/orca-trading.git
cd orca-trading

# Create virtual environment
python -m venv venv
source venv/bin/activate  # Sur Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run data collection
python src/data/fetcher.py
